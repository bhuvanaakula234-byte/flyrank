# FlyRank Backend AI Engineering – Week 3

## Project
Task Management REST API using Node.js, Express and SQLite.

## Features
- Create Tasks
- Read Tasks
- Update Tasks
- Delete Tasks
- SQLite Database

## Database
SQLite is used because it is lightweight, fast, and stores data in a single file (`tasks.db`).

## Installation

```bash
npm install
```

## Run the Project

```bash
node server.js
```

## API Endpoints

- GET /tasks
- GET /tasks/:id
- POST /tasks
- PUT /tasks/:id
- DELETE /tasks/:id

## Example SQL Query

```sql
SELECT * FROM tasks;
```

## Database File

```
tasks.db
```
